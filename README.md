# Shahid Hameed Portfolio

Premium personal portfolio website for Shahid Hameed, AI Engineer.

## Local Preview

Open `index.html` directly in a browser, or run a static server from this folder:

```bash
python -m http.server 3000
```

Then visit `http://localhost:3000`.

## Vercel Deployment

1. Create a new GitHub repository.
2. Upload these files to the repository.
3. In Vercel, choose **Add New Project** and import the repository.
4. Use the default static project settings.
5. Deploy.

After deployment, update `robots.txt` and `sitemap.xml` with the real Vercel URL or custom domain.
